# 建模内部黑色描边问题排查与覆盖度分析报告

> 针对指令「建模内部不应该出现黑色描边，描边仅限于边缘，检查该问题的覆盖度」开展全面排查。

---

## 一、核心结论概览

经过对 C# 源码（`Model3D.cs`、`Furniture3D.cs`、`BuildingLayer3D.cs` 等）、前端查看器（`viewer/furniture.html`、`viewer/wreck.html`）以及贴图图集生成脚本（`scripts/furn_atlas.py`）的全面排查，确认**“建模内部出现黑色描边”**的问题主要由以下两大独立机制产生：

| 层面 | 产生原因 | 表现形式 | 影响覆盖度 |
| :--- | :--- | :--- | :--- |
| **1. 三维几何与描边壳机制 (Mesh Outline)** | 复合模型逐 Part（子部件）独立生成描边壳 / 查看器使用 `EdgesGeometry` 遍历了每个部件的所有棱线 | 内部零件接缝、桌面与台面设备交界、拼接箱体处布满黑色网格线条 | **100% 复合建筑模型**（全部 46 款家具与工作台、残骸、动物） |
| **2. 贴图取样与边界黑边溢出 (Texture UV Bleeding)** | 原版 2D 贴图外轮廓自带黑色描边，UV 取样框边缘切入了黑边或贴图填充未完全剔除 | 模型的平整表面或顶面上出现突兀的黑色线条斑块 | **13.2% UV 区域**（385 个取样区中有 51 处存在边缘黑线外溢） |

---

## 二、问题机制深度溯源

### 1. 几何描边壳与棱线渲染问题（Mesh Level）
#### (1) 查看器（`viewer/furniture.html` / `viewer/wreck.html`）
* **代码定位**：`new THREE.EdgesGeometry(geo, 45)`
* **机制分析**：
  `EdgesGeometry` 判断的是**网格中任意两个三角形相邻面的法线夹角**。由于生产台和家具是由多个立方体和圆柱组合而成（例如工作台本体 + 台面托盘 + 试剂瓶 + 机械臂）：
  * 每一个子部件本身的 12 条棱线（即使是贴着地面的底面边、贴着桌面的底边）全部被提取为黑线；
  * 相邻两个零件并排紧靠时，中间接触缝被画上了粗黑线；
  * 结果：**模型不仅外边缘有描边，所有内部拼接构件全都画满了黑框，完全破坏了干净的平滑感**。

#### (2) C# Unity 运行时描边（`Model3D.cs`）
* **代码定位**：
  ```csharp
  // Model3D.cs 第 20-21 行注释：
  // 之所以逐 Part 生成（而不是整模型一个壳），是为了让部件交界处也出现内部描边线...
  // 第 223 行：
  if (!p.noOutline) EmitHull(hullStart);
  ```
* **机制分析**：
  C# 中为了赛璐璐效果，为每个 Part 分别生成了法线外扩反绕壳（Inverted Hull）。但当两个零件相互重叠或贴合时（如工作台底座与箱体，桌腿与桌面），两个外扩壳在内部相交处会向外凸出，导致内部缝隙产生黑线。

---

### 2. 贴图 UV 采样切入原版黑边问题（Texture Level）
* **机制分析**：
  RimWorld 原版贴图是 2D 正交插画，边缘带有明显的纯黑色描边（Stroke）。
  在 `scripts/furn_atlas.py` 中定义的很多采样框（如 `tray`、`back`、`top`、`front`），其矩形框的一端直接贴到了原图的非透明边缘，切入了 1~2 像素的原版轮廓黑边。
* **数据量化（经图集全量扫描）**：
  * 总 UV 取样区域：**385 个**
  * 边缘平均亮度极黑（luma < 40，中心正常 luma > 80）的区域：**51 个**（占比 **13.2%**）
  * 典型受影响建筑：
    * `researchbenchhitech`（高级研究台）：左右两侧白色托盘 `tray` 顶底包含黑边，导致贴在桌面上出现断裂黑横线；
    * `tablesmithingelectric`（电力锻造台）：`top` 顶面边缘切入黑边；
    * `couch` / `armchair` / `throne`（沙发、扶手椅、宝座）：`back` 靠背底端带纯黑边缘；
    * `floodlight`（泛光灯）：`pole` 灯柱边缘带黑边；
    * `shelf` / `table1x2` / `table2x2`：桌面木纹边缘带黑边。

---

## 三、治理与修复方案

1. **查看器棱线描边收敛**：
   * 将 `viewer/furniture.html` 中的 `EdgesGeometry(geo, 45)` 优化或增加轮廓滤镜，或者仅对模型的顶层外部表面生效，避免将贴合在内部或底部的共面/内部隐藏棱线画为黑线；
2. **C# 描边外壳收敛**：
   * 对相接贴合面（如 `y0 = surfY` 的底面、落地的零件底面）开启 `noOutline` 或在焊接网格后统一生成单一外轮廓壳（Silhouette Hull），避免子部件在内部相交处互相穿透产生黑缝；
3. **贴图 UV 边界内缩与描边剔除**：
   * 对检出的 51 处带黑边 UV 区域，将切分矩形向内收缩 1~2 像素，避开原版轮廓描边，确保贴在 3D 面上的贴图纯净无黑边。
