# 上帝视角画在手持终端的屏幕上

## 背景

视角切换已经有道具：`1.6/Assets/hand_terminal.obj`，`HandTerminal3D` 会把它抬到眼前。屏幕四边形是程序生成的，贴的是自绘 UI 和扫描线。

`MapScreen3D` 在抬起动画结束后把主相机还原成原版正交俯视，并放开全部原版绘制和 UI。玩家离开第一人称，终端本身不再出现。

## 决定

- 道具继续用这一份 OBJ。不另做地图板或全息仪。
- M 键的终态：主相机保持第一人称透视；原版正交地图相机渲染到 `RenderTexture`，贴到终端屏幕面上。
- 在屏幕上要能完成现在全屏上帝视角能做的事：看殖民地、平移、点选殖民者后再回到这个人的第一人称。输入命中屏幕时才交给这台地图相机，其余输入仍归第一人称。
- 三维场景在开关期间都不销毁。这一点与现在的 `MapScreen3D` 相同。
- 现有的整屏闪白切回，只作为该功能落地前的临时路径。`F002` 完成后删除整屏接管。

## 后果

`VanillaSuppressor` 按整帧跳过 `DrawMapMesh` 和动态绘制。不能为了终端把这一跳过整帧关掉：`Graphics.DrawMesh` 会进本帧所有相机的队列，主相机就会看见原版地图，`Fps3DRoot` 的旧 `Open` 分支还会 `Leave3D`。落地做法是捕获窗：只在调用那两次绘制时放行，并把提交转到 layer 31 的停用正交相机，`Camera.Render()` 写入屏幕 RT。主相机每帧排除这一层。

原版 UI 根节点是屏幕空间的。屏幕上的平移和点选 pawn 用射线打屏幕四边形，不把 `UIRoot` 画进网格。
