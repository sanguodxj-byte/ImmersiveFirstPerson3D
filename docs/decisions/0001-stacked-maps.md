# 垂直楼层与水平邻图都用多张 Map 拼接

## 背景

环世界的 `Map` 是一张 XZ 格子。绘制用的世界 Y 是 `Altitudes` 分层，不是楼层高度。一张图里没有第二层格子，也没有「走出东边缘继续走」的连续坐标。

## 决定

- **楼上是另一张 Map。** `LevelStack3D` 把多张图排成栈，绘制时 Y 加 `层号 × 3.00 m`（室内净高 2.70 + 楼板 0.30）。玩法上的上下楼，是让附身者在这些图之间移动，而不是给格子增加一个 Y 索引。
- **邻接大陆是另一张 Map，加上世界 XZ 偏移。** `Streaming3D` 登记偏移。渲染集合 = 当前垂直栈 ∪ 已登记邻图。
- **存档只存 ID 和偏移。** 地图本身交给原版。见 `WorldLinkComponent`。
- **上层图和流式图都必须有有效世界格。** 口袋图抄底层 `Tile` 并进入 `pocketMaps`。流式图用 `FP3D_StreamNode`，不用会被原版自动拆除的营地 Def。

## 后果

切层、跨边、卸载都要处理「人在哪张图上」。相机和碰撞用世界坐标，寻路和 `CurrentMap` 仍是原版单图语义。流式加载任务扩大邻接半径时，沿用偏移表，不合并成一张巨型 `Map`。

山体高度是网格上的米，不是新的地图层。一层楼内部的岩壁可以高于 2.70 m，那仍然属于这一张图的绘制，不为此再开一张 Map。
