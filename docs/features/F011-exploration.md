# F011: 自由探索闭环

> Status: spec | Owner: TBD

## Why

能走、能瞄准、能跨图之后，第一人称仍然是「征召殖民者的另一种相机」。终态是 ARPG 式的自由探索：人在场景里移动，环境有明暗，未知区域有揭示，战斗从准星进入，结算留在原版。

## What

- 照明：见 F013（`docs/features/F013-lighting.md`）。本项只要求探索节奏用上它给的明暗，不另定一套亮度口径。
- 揭示：第一人称下殖民者视野内的雾按原版规则揭开。相机不揭开视野外的雾。
- 兴趣点：准星命中可交互物时沿用 F004 的名称标签。地图屏幕（F002）用来查看已揭示的全局。
- 战斗入口就是 F004 的 verb。本项补上被击中时的反馈：屏幕边缘红色、附身者死亡则退出第一人称并还原原版相机。
- 不新增需求条、经验或武器数值。

## Acceptance Criteria

- [ ] AC-1: 有屋顶且无灯的房间暗于室外正午；打开灯或走到窗边后变亮。亮度由 F013 从 `GlowGrid` 取。
- [ ] AC-2: 走进雾边，雾按原版视野揭开；转身离开后，视野外不因相机曾经对着它而揭开。
- [ ] AC-3: 被敌人命中时屏幕边缘出现受击提示；殖民者死亡后三维模式关闭，原版俯视恢复。
- [ ] AC-4: 从基地走到邻图（F010）再打开终端屏幕（F002），屏幕上能看到已经走过的两张图的俯视。

## Dependencies

F003、F004、F010。F002 只被 AC-4 使用；若 F002 未完成，AC-4 降级为「原版全屏地图里能看到两张图」，不阻塞前三条。

## Risk

`GlowGrid` 是格子亮度，不是逐像素。第一版按格取亮度乘到该格几何上，允许格与格之间有台阶，不要求平滑光照。
