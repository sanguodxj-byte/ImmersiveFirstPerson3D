# F006: 山体与大型岩体

> Status: spec | Owner: TBD

## Why

天然岩是 `Fillage.Full` 的建筑，因此和人造墙一样被挤成 2.70 m 的盒子。地图上的山在第一人称里应该是高过室内的整块岩体。`SkyScenery` 的远山是装饰视差，不读 `thingGrid`，不能算山体建模。地形层现在是平的四边形，大型地表（岩顶、坑）没有体积。

## What

- 判定：满格、且 def 属于原版可挖岩（mineable），不包含玩家建造的墙。墙仍走 F005。
- 同一连通域的岩格合成一块网格：侧面用原版岩贴图，顶面用原版岩顶或同一贴图的顶区。贴图只作材质，不新建美术贴图。
- 高度：岩体顶高于 `WallHeight`，取 `Metrics3D` 中新增的山体高度常数（写明现实依据：人在山壁下抬头仍看见岩，而不是室内天花）。连通域边缘可以收成斜坡楔形，楔形用 `Model3D` 已有的 `Wedge`。
- 挖掘一格后该格退出岩体，邻格露出新的侧面。脏范围限于该连通域碰到的 chunk。
- 蒸汽喷泉继续地面片，不包进岩体。

## Acceptance Criteria

- [ ] AC-1: 站在山脚抬头，岩壁连续且高于 2.70 m 的室内墙，侧面纹理是该岩种的原版贴图。
- [ ] AC-2: 挖掉一块岩后，出现新的侧面，不留下空洞或双层皮。
- [ ] AC-3: 人造墙的高度仍是 2.70 m，不跟着山体变高。
- [ ] AC-4: 岩体内部的面被剔除，一块 20×20 的实心岩域侧面三角形数量与表面积同阶，而不是 400 个实心盒子。

## Dependencies

无。和 F005 分列是为了能并行。两者都改 `BuildingLayer3D` 的满格分支时，先按「可挖岩 / 其他满格」拆开函数再各改各的。

## Risk

山体高于一层楼时会穿过楼上的地图。F008 / F009 落地前，山体高度钳在单层净空以上、下一层楼板以下，避免穿模。多楼层的山体贯通留到 F009 之后。
