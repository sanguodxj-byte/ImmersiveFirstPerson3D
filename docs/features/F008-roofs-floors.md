# F008: 屋顶与楼板

> Status: spec | Owner: TBD

## Why

室内净高 2.70 m 已经用在墙上，但没有天花板。第一人称抬头就是天空盒。屋顶数据在原版 `RoofGrid`，现在只被草地用来跳过有屋顶的格子。楼上那张图的地面是另一张地形层，层与层之间没有 0.30 m 的楼板实体。

## What

- 读 `RoofGrid`。有屋顶的格在 `baseY + WallHeight` 放天花板，材质用原版屋顶贴图。
- 若该格上方同一栈存在下一层地图，再在天花板之上放 `FloorThickness`（0.30 m）的楼板，顶面用上层该格的地形材质。
- 建造墙的顶与天花板相接，不留缝。
- 拆掉屋顶的格在同一 chunk 预算内去掉天花板。

## Acceptance Criteria

- [ ] AC-1: 站在有屋顶的房间里抬头，看见连续天花板，看不见天空盒。
- [ ] AC-2: 走到室外，抬头是天空，没有天花板延伸到室外格。
- [ ] AC-3: 存在上层地图时，楼下天花板与楼上地板之间的空隙等于 0.30 m，楼上地形纹理出现在楼板顶面。
- [ ] AC-4: 拆掉一格屋顶后，该格恢复露天，邻格天花板仍在。

## Dependencies

F005。墙顶高度以建造墙的 `WallHeight` 为准，楼板对齐这个高度。

## Risk

原版屋顶按格，厚屋顶和薄屋顶的贴图不同。第一版可以共用一个厚度，用各自的屋顶材质区分外观。山体（F006）在本项之前被钳在楼板之下。
